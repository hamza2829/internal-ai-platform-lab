# Anwendungsbeispiele

Alle Beispiele sind erfunden und beschreiben keine echte Abteilung, Kundschaft oder Firma.

- **Vertrieb:** Fragen zur Bedarfsermittlung aus einer erfundenen Prospect-Zusammenfassung vorbereiten; keine Rabatte erfinden oder Nachrichten versenden.
- **Produktentwicklung:** Eine erfundene Produktfrage in Hypothese, Messgröße und kleines Experiment übersetzen.
- **Kundenservice:** Einen umkehrbaren Troubleshooting-Schritt mit Eskalation entwerfen; keine Konten ändern oder Erstattungen versprechen.
- **Marketing:** Eine erfundene Kampagnenaussage auf Belege und Barrierefreiheit prüfen; keine Testimonials oder Ergebnisse erfinden.

Jeder Skill liegt unter `library/skills/<abteilung>/<name>/SKILL.md` und enthält Anweisungen sowie Beispiel. Die Werte in `evals/skills.json` sind Rubrik-Ziele und kein gemessener Modell-Benchmark.
