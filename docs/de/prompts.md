# Leitfaden zum Schreiben von Prompts

1. Aufgabe und Zielgruppe nennen.
2. Nur freigegebenen, erfundenen oder anonymisierten Kontext geben.
3. Format und Länge der Antwort vorgeben.
4. Grenzen nennen: keine Fakten, Zusagen oder Belege erfinden.
5. Beschreiben, wann nachgefragt oder eskaliert werden soll.
6. Ein normales Beispiel sowie ein Ablehnungs- oder Eskalationsbeispiel ergänzen.
7. Prompt versionieren und mit repräsentativen Fällen auswerten.

Bevorzuge überprüfbare Anweisungen („nenne drei Fragen“) statt vager Begriffe („sei strategisch“). Trenne Quellenfakten von Annahmen und lasse folgenreiche Entwürfe von Menschen prüfen.
