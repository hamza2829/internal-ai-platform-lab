# Prompt writing guide

1. State the task and intended reader.
2. Provide only approved, fictional or anonymized context.
3. Specify the answer structure and length.
4. Name boundaries: do not invent facts, commitments, or evidence.
5. Say when to ask for clarification or escalate.
6. Include one normal example and one refusal or escalation example.
7. Version the prompt and evaluate it against representative cases.

Prefer observable instructions (“return three questions”) over vague wording (“be strategic”). Separate source facts from assumptions and ask a person to review consequential drafts.
